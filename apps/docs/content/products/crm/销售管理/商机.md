# 商机

## 1. 产品定位

### 1.1 解决什么问题

商机是唯一的销售预测对象，记录可预期交易的阶段、金额、预计成交日和下一步。

### 1.2 使用角色

销售推进本人商机；主管管理部门漏斗；管理员维护全部管道与阶段配置。

### 1.3 与其他模块的关系

商机必须关联客户，可选关联联系人；关联产品、报价、合同、回款和活动。客户是商机的业务主体，商机不依赖任何前置业务对象的阶段切换而创建。

## 2. 核心业务流程

创建商机 → 维护阶段、金额和下一步 → 添加产品与报价 → 赢单后创建合同 → 按合同跟踪回款；丢单时记录原因。

## 3. 页面设计

### 3.1 列表页

| 区块 | 设计 |
| --- | --- |
| 视图 | `ProTable` 列表与按阶段分列的管道看板。 |
| 搜索 | 关键字、管道、阶段、负责人、客户、预计成交日范围、来源。 |
| 列 | 商机名称、客户、阶段、预计金额、预测金额、预计成交日、下一步、负责人、操作。 |
| 操作 | 查看、编辑、推进阶段、写跟进、创建报价、赢单、丢单。 |

### 3.2 详情页

| 区块 | 内容 |
| --- | --- |
| 顶部 | 商机名称、阶段、金额、负责人和推进动作。 |
| 销售信息 | 客户、联系人、管道、阶段、概率、预计金额、预测金额、预计成交日、下一步。 |
| 关联 | 产品、报价、合同、回款和活动时间线。 |
| 风险 | 无下一步、逾期活动、临近成交日和长期未推进提示。 |

### 3.3 新建 / 编辑

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 商机名称、客户 | 文本、客户选择 | 是 | 客户必须正常、可见且生命周期不为已无效。 |
| 联系人、负责人 | 选择 | 否 | 联系人应属于所选客户。 |
| 管道、阶段 | 枚举下拉 | 是 | 阶段由管道配置。 |
| 预计金额、预计成交日 | 金额、日期 | 是 | 用于预测。 |
| 下一步 | 活动选择 | 是 | 进行中商机必须有计划动作。 |

## 4. 数据模型

### 4.1 核心字段

名称、客户、联系人、负责人、管道、阶段、预计金额、阶段概率、预测金额、预计成交日、下一步、赢单或丢单原因。

### 4.2 状态

进行中阶段由设置维护，默认需求确认、方案沟通、商务谈判；赢单、丢单是结果，不与阶段混用。

### 4.3 关联关系

商机关联一个客户、可选联系人，多个产品和报价，最多一个最终合同及其回款。

## 5. 功能需求

### 5.1 查询

支持列表和管道视图，按阶段、金额、成交日和下一步排序筛选。

### 5.2 新增

可从客户详情或商机列表创建；默认负责人为创建人。商机列表创建时必须选择一个正常、可见且生命周期不为已无效的客户。

### 5.3 编辑

可维护金额、成交日和下一步；阶段变化记录时间线。

### 5.4 状态流转

阶段可按管道推进或回退；赢单需关联合同或填写跳过原因；丢单必须选择丢单原因。

### 5.5 删除 / 作废

无报价、合同和回款时可软删除；存在经营事实时仅允许丢单或归档。

## 6. 权限与数据可见性

### 6.1 查看权限

按负责人、部门和管理员全量范围查看。

### 6.2 操作权限

商机查看、创建、编辑、阶段推进、赢单、丢单和转移分别授权。

### 6.3 数据范围

客户可见性、正常档案状态和非已无效生命周期是创建商机的前置条件；商机归属决定后续报价和合同默认范围。

## 7. 业务规则

预测金额等于预计金额乘阶段默认概率；概率由阶段配置，销售不可逐条任意修改；无下一步只提示，不在 P0 阻断。

## 8. 异常与边界场景

丢单后不可新增报价；赢单后阶段不可继续推进；联系人不属于客户时不可关联；金额不得为负。

## 9. MVP 范围

### 9.1 P0

管道、阶段、金额、预测、下一步、产品、报价、赢单丢单和活动。

### 9.2 P1

协同团队、预测模型、审批门禁和竞争对手分析。

### 9.3 暂不支持

AI 预测和复杂多管道权限。

## 10. 验收标准

销售可用列表和看板推进商机；主管可按阶段和预测金额查看漏斗；赢单、丢单和关键字段变更均可追溯。

## 11. 字段契约与交互细则

| 动作 / 字段 | 触发与前置条件 | 系统反馈与结果 | 异常恢复 / 审计 |
| --- | --- | --- | --- |
| 客户、联系人 | 新建或编辑 | 仅可选正常、可见且非已无效客户；联系人随客户联动过滤 | 客户切换时清空不归属的新联系人并提示。 |
| 阶段推进 | 列表、看板卡片或详情；具推进权 | 显示目标阶段与默认概率，确认后更新预测金额和时间线 | 已赢单/丢单不可推进；冲突时刷新阶段后重试。 |
| 赢单 / 丢单 | 详情操作 | 赢单关联合同或填写跳过原因；丢单必填原因 | 确认弹窗说明影响；记录结果、原因和操作者。 |
| 下一步 | 新建、编辑或写跟进 | 进行中商机缺失时显示风险提示 | 逾期标签可点击筛选；不在 P0 阻断保存。 |

## 12. 页面状态

看板按阶段加载骨架和空列；拖拽卡片前校验目标阶段权限，失败后卡片回到原列并提示原因。无可选客户时新建入口仍可打开，但客户选择器说明不可创建原因。

## 13. UX 规格

页面用 `PageContainer`，标题右侧为“新增商机”；`Segmented` 切换 `ProTable` 与管道看板，保留当前筛选。看板以 `Row` 按阶段分列，列头显示阶段、数量和预测金额，卡片显示名称、客户、金额、成交日与负责人；拖拽以阶段确认 `Modal` 收口。详情为 900 宽 `Drawer`：顶部固定名称、阶段和操作，左侧资料、产品/报价/合同/回款 Tabs，右侧风险卡与活动时间线。新建/编辑使用 640 宽 `ModalForm`，客户优先选择并联动联系人、管道和阶段；赢单、丢单均使用必填原因/关联合同的确认表单。
