# @yishan/docs

独立文档产品，沿用 Docusaurus 3.9.2、React 19、现有主题、首页、侧栏和 /docs/... URL。生产域名 https://docs.zerocmf.com 和 baseUrl / 保持原值；本次只调整源码组织，不执行发布。

## 运行与构建

从仓库根目录使用 .tool-versions 和 packageManager 固定的工具链：

~~~bash
pnpm install --frozen-lockfile
pnpm dev:docs
pnpm --filter @yishan/docs typecheck
pnpm --filter @yishan/docs build
pnpm --filter @yishan/docs serve --host 127.0.0.1 --port 4000 --no-open
~~~

开发默认端口 4000。需要其他端口可运行 pnpm --filter @yishan/docs start --port 4100 --no-open。文档产品不需要 API、数据库、Redis 或 TipTap 构建；根 pnpm build:docs 等价于独立构建，产物为 build/。

## 组织与内容维护

| 目录 | 用途 |
| --- | --- |
| app/pages | 首页和可访问页面，由 preset-classic.pages.path 指定 |
| app/css | 保留原全局样式 |
| components | 本产品的 React 组件，使用 @site/components/... |
| content | 唯一产品文档来源，由 docs.path 指定；文档 ID 与 /docs URL 不随物理目录改变 |
| config | Docusaurus 配置和 sidebars.ts；CLI 显式 --config |
| public | 原 static 图片及资源，使用 staticDirectories；公开 /img/... URL 保持不变 |

在 content/ 的快速开始、API、前端、模块、部署或 products/ 中添加 Markdown/MDX；显式章节在 config/sidebars.ts 注册，CRM 产品规格使用 Docusaurus 官方 autogenerated category。frontmatter 可设置 title/slug/sidebar_position；slug 变更需审查公开链接。内部内容链接使用相对 .md 或现有 /docs/... URL。源码 import 只使用公开 Package exports 或本地 @site 路径，产品之间不能互相导入。

CRM 规格包含规划和 archive 历史说明，不能据此认定 Demo 已安装 CRM。根 docs/ 的 ADR、治理规范、计划、数据库审计和验收截图不进入站点；不通过额外 plugin 同时扫描根目录，不复制第二套正文。治理入口仅链接到权威来源。

## 发布

先执行独立 typecheck/build 与 pnpm check:boundaries，再通过 serve 检查首页、侧栏、深链及资源。经明确发布授权后，把 build/ 内容作为独立静态站部署到既有文档站托管位置；确认域名、baseUrl、静态资源及深链回退策略。源码无需 API 服务，也不导入后端运行时代码。

保留 Docusaurus 官方 deploy 命令和既有 GitHub Pages 元数据；使用该命令前必须核实目标仓库、部署分支和权限，它不是本次自动发布步骤。当前 Fullstack CI 负责类型检查与静态构建，不发布站点。不要上传 .env、node_modules、源码缓存或其他产品产物。

文档所有权与贡献规则见 [documentation-system.md](../../docs/architecture/documentation-system.md) 和 [contributing.md](../../docs/contributing.md)。
