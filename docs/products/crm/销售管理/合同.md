# 合同

## 1. 产品定位

### 1.1 解决什么问题

记录客户与组织之间最终签约和履约事实，为回款计划提供金额边界。

### 1.2 使用角色

销售创建并维护合同；主管管理部门合同；管理员维护状态和归档。

### 1.3 与其他模块的关系

合同关联客户和商机，可从已接受报价带入，关联回款计划、回款记录和 P1 工单。

## 2. 核心业务流程

从商机或报价创建草稿 → 确认签约信息 → 待签约 → 履约中 → 完成或作废 → 按合同建立回款计划。

## 3. 页面设计

### 3.1 列表页

| 区块 | 设计 |
| --- | --- |
| 搜索 | 关键字、状态、客户、商机、负责人、签约日期和到期日期范围。 |
| 列 | 合同编号、名称、客户、商机、合同金额、状态、到期日期、负责人、操作。 |
| 操作 | 查看、编辑草稿、提交待签约、确认履约、完成、作废。 |

### 3.2 详情页

| 区块 | 内容 |
| --- | --- |
| 顶部 | 合同编号、状态、合同金额、负责人和状态动作。 |
| 合同资料 | 客户、商机、报价、签约日、生效日、到期日、附件和说明。 |
| 回款 | 回款计划、实际回款、待回金额和逾期摘要。 |
| 时间线 | 合同状态、附件和回款相关变更。 |

### 3.3 新建 / 编辑

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 合同名称、客户、商机 | 文本、选择 | 是 | 商机应属于客户。 |
| 报价 | 报价选择 | 否 | 仅可选择已接受报价。 |
| 合同金额 | 金额 | 是 | 不得为负，确认后独立于报价。 |
| 签约、生效、到期日期 | 日期 | 是 | 日期顺序合法。 |
| 附件、说明 | 上传、多行文本 | 否 | 记录合同文件和补充信息。 |

## 4. 数据模型

### 4.1 核心字段

编号、名称、客户、商机、报价、金额、签约日、生效日、到期日、状态、负责人、附件和说明。

### 4.2 状态

草稿、待签约、履约中、已完成、已作废。

### 4.3 关联关系

合同关联一个客户和商机，可关联报价、多个回款计划、回款记录和工单。

## 5. 功能需求

### 5.1 查询

支持状态、客户、商机、负责人和日期范围查询。

### 5.2 新增

支持从赢单商机或已接受报价创建，也支持直接创建。

### 5.3 编辑

草稿和待签约可编辑；履约中合同金额修改需创建变更记录。

### 5.4 状态流转

待签约确认后进入履约中；回款计划全部完成且履约结束后可完成；作废需填写原因。

### 5.5 删除 / 作废

草稿可删除；产生回款计划或实际回款后只能作废，不删除。

## 6. 权限与数据可见性

### 6.1 查看权限

继承客户和商机的数据范围。

### 6.2 操作权限

创建、编辑、状态变更、作废、附件和导出分别授权。

### 6.3 数据范围

合同负责人及部门决定默认可见范围。

## 7. 业务规则

合同金额是最终约定事实，不随报价后续修改；回款计划总额不得超过合同金额。

## 8. 异常与边界场景

日期顺序错误不可保存；已完成或作废合同不可新增回款计划；有实际回款的合同不可删除。

## 9. MVP 范围

### 9.1 P0

合同资料、状态、附件、回款计划关联和金额边界。

### 9.2 P1

审批、模板、电子签、版本归档和续约提醒。

### 9.3 暂不支持

法务协同和电子签平台同步。

## 10. 验收标准

销售可从商机或报价创建合同，维护履约状态并建立不超过合同金额的回款计划。

## 11. 字段契约与交互细则

| 动作 / 字段 | 触发与前置条件 | 系统反馈与结果 | 异常恢复 / 审计 |
| --- | --- | --- | --- |
| 客户、商机、报价 | 新建或编辑 | 商机随客户过滤，报价仅显示该商机已接受版本 | 关联不一致时阻断并定位字段。 |
| 金额与日期 | 失焦、提交 | 金额不得为负；校验签约、生效、到期顺序 | 失败提示具体日期或金额规则，保留输入。 |
| 提交、履约、完成、作废 | 详情状态操作 | 确认弹窗展示状态影响；作废必填原因 | 有回款时禁止删除；金额变更和作废原因写入时间线。 |

## 12. 页面状态

草稿可编辑，其他状态按权限只读或显示可用动作；回款计划为空时提供建立计划入口。附件上传中禁用提交并显示进度，失败可逐个重试。
