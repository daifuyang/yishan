# 工单

## 1. 产品定位

### 1.1 解决什么问题

工单用于承接客户售后问题、服务请求和处理过程，与销售闭环解耦。

### 1.2 使用角色

售后人员在 P1 受理和处理；销售查看本人客户的工单摘要；管理员维护类型、优先级和 SLA。

### 1.3 与其他模块的关系

工单必须关联客户，可选关联合同、产品、联系人和商机；不改变商机阶段、合同金额或回款事实。

## 2. 核心业务流程

客户提出请求 → 创建工单 → 受理并分派 → 处理与记录沟通 → 客户确认 → 关闭工单。

## 3. 页面设计

### 3.1 列表页

| 区块 | 设计 |
| --- | --- |
| 搜索 | 关键字、状态、类型、优先级、客户、负责人、创建时间和 SLA 状态。 |
| 列 | 工单编号、主题、客户、类型、优先级、状态、负责人、SLA 到期、创建时间、操作。 |
| 操作 | 查看、编辑、受理、分派、开始处理、请求确认、关闭。 |

### 3.2 详情页

| 区块 | 内容 |
| --- | --- |
| 顶部 | 工单编号、主题、状态、优先级、负责人和状态动作。 |
| 基本资料 | 客户、联系人、合同、产品、类型、问题描述、附件。 |
| 处理 | 受理时间、处理记录、解决方案、客户确认、关闭原因。 |
| 时间线 | 创建、分派、沟通、状态变更和 SLA 事件。 |

### 3.3 新建 / 编辑

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 客户、主题、问题描述 | 选择、文本、多行文本 | 是 | 客户必须可见。 |
| 联系人、合同、产品 | 选择 | 否 | 应归属所选客户。 |
| 类型、优先级 | 枚举下拉 | 是 | 设置维护。 |
| 负责人、附件 | 人员选择、上传 | 否 | 可在受理时补充。 |

## 4. 数据模型

### 4.1 核心字段

编号、主题、客户、联系人、合同、产品、类型、优先级、状态、负责人、问题描述、解决方案、SLA 时间和附件。

### 4.2 状态

待受理、处理中、待确认、已关闭。

### 4.3 关联关系

工单关联一个客户，可选关联合同、产品、联系人和商机；可关联多个处理活动。

## 5. 功能需求

### 5.1 查询

支持关键字、状态、类型、优先级、客户、负责人、时间和 SLA 查询。

### 5.2 新增

P1 支持从客户详情、合同详情和工单列表创建。

### 5.3 编辑

待受理和处理中可维护问题与处理信息；关闭后仅允许追加审计备注。

### 5.4 状态流转

受理后进入处理中；解决后请求客户确认；确认后关闭；重新打开需记录原因。

### 5.5 删除 / 作废

仅待受理且无处理记录的工单可删除；其他工单作废并保留历史。

## 6. 权限与数据可见性

### 6.1 查看权限

售后按负责人和部门查看；销售仅查看本人客户的工单摘要；管理员查看全部。

### 6.2 操作权限

创建、受理、分派、处理、确认、关闭、重开和 SLA 配置分别授权。

### 6.3 数据范围

客户可见性和工单负责人共同决定可见范围。

## 7. 业务规则

工单不改变销售金额或商机阶段；类型、优先级和 SLA 由设置维护；关闭必须有解决方案或关闭原因。

## 8. 异常与边界场景

无可见客户不可建单；关闭后不可直接编辑；跨客户关联合同或联系人不允许；SLA 变更留痕。

## 9. MVP 范围

### 9.1 P0

仅定义对象边界、字段、页面和与客户、合同的关系。

### 9.2 P1

受理、分派、处理、确认、关闭、SLA、通知和知识库关联。

### 9.3 暂不支持

服务门户、自动路由、外部工单同步和复杂 SLA 升级。

## 10. 验收标准

P1 实施后，售后可创建、受理、分派、处理和关闭客户工单；销售仅能查看本人客户的必要摘要，销售漏斗不受工单状态影响。

## 11. 字段契约与交互细则

| 动作 / 字段 | 触发与前置条件 | 系统反馈与结果 | 异常恢复 / 审计 |
| --- | --- | --- | --- |
| 客户、联系人、合同 | 创建或编辑 | 关联对象按客户联动过滤 | 无访问权或关联不一致时阻断并说明原因。 |
| 受理、分派、处理 | 详情状态操作 | 受理写入时间；分派选择可处理人员；处理记录追加到时间线 | 状态不匹配时刷新详情后重试。 |
| 请求确认、关闭、重开 | 具对应权限 | 关闭和重开均要求原因并二次确认 | 记录前后状态、原因与操作者。 |

## 12. 页面状态

待受理、处理中、待确认、已关闭在详情顶部可见；无处理记录时引导新增。关联客户不可见时仅显示“无访问权限”，不泄露客户资料。
