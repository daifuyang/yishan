# 拜访

## 1. 产品定位

### 1.1 解决什么问题

将线下拜访作为可追溯的高价值活动，沉淀计划、纪要、结果和下一步。

### 1.2 使用角色

销售记录本人拜访；主管查看团队拜访；管理员维护拜访结果枚举。

### 1.3 与其他模块的关系

拜访是活动类型，可关联客户、联系人、商机、报价或合同，不重复建设独立销售主对象。

## 2. 核心业务流程

创建拜访计划 → 执行拜访 → 记录实际时间、参与人、纪要和结果 → 创建下一步活动 → 在关联对象时间线展示。

## 3. 页面设计

### 3.1 列表页

| 区块 | 设计 |
| --- | --- |
| 视图 | 我的拜访、团队拜访、日历与 `ProTable` 列表。 |
| 搜索 | 关联对象、客户、商机、负责人、计划时间、实际时间、结果。 |
| 列 | 拜访主题、客户、商机、计划时间、实际时间、结果、下一步、负责人、操作。 |
| 操作 | 查看、编辑、开始、完成、取消。 |

### 3.2 详情页

| 区块 | 内容 |
| --- | --- |
| 计划 | 主题、关联对象、计划时间、地点、参与人。 |
| 实际 | 实际时间、纪要、结果、附件和下一步。 |
| 时间线 | 拜访创建、完成和关联对象活动记录。 |

### 3.3 新建 / 编辑

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 关联对象 | 选择 | 是 | 客户、联系人、商机、报价或合同至少选择一个；关联联系人、商机、报价或合同时必须可追溯到客户。 |
| 主题、计划时间 | 文本、日期时间 | 是 | 用于工作台待办。 |
| 地点、参与人 | 文本、人员选择 | 否 | 补充现场信息。 |
| 纪要、结果、下一步 | 多行文本、枚举、活动选择 | 完成时必填纪要 | 结果枚举由设置维护。 |

## 4. 数据模型

### 4.1 核心字段

关联对象、主题、计划时间、实际时间、地点、参与人、纪要、结果、下一步和附件。

### 4.2 状态

计划中、已完成、已取消。

### 4.3 关联关系

拜访作为活动记录写入关联客户、联系人、商机、报价和合同的时间线。

## 5. 功能需求

### 5.1 查询

支持按对象、负责人、时间和结果查询。

### 5.2 新增

支持从关联对象详情、工作台和拜访列表创建。

### 5.3 编辑

计划中可编辑；完成后纪要修改需留痕。

### 5.4 状态流转

计划中可完成或取消；完成时填写实际信息和纪要。

### 5.5 删除 / 作废

计划中可删除；已完成活动只能作废并保留记录。

## 6. 权限与数据可见性

### 6.1 查看权限

继承关联主对象的数据范围。

### 6.2 操作权限

活动创建、编辑、完成、取消和附件分别授权。

### 6.3 数据范围

负责人和关联对象可见性共同决定拜访可见性。

## 7. 业务规则

拜访不单独改变客户生命周期或商机阶段；完成拜访可创建下一步，但不强制。

## 8. 异常与边界场景

无可见关联对象不可创建；已取消不可完成；实际时间不得早于计划时间需二次确认。

## 9. MVP 范围

### 9.1 P0

计划、完成、纪要、结果、下一步、独立列表和关联时间线。

### 9.2 P1

签到、定位、路线和外勤统计。

### 9.3 暂不支持

自动地理围栏和费用报销。

## 10. 验收标准

销售可从客户或商机创建、完成拜访并记录纪要；拜访可在独立列表和关联对象时间线中查询。

## 11. 字段契约与交互细则

| 动作 / 字段 | 触发与前置条件 | 系统反馈与结果 | 异常恢复 / 审计 |
| --- | --- | --- | --- |
| 关联对象 | 新建首字段 | 选择客户、联系人、商机、报价或合同；自动回显客户上下文 | 不可见或关系不一致时不可保存并说明原因。 |
| 开始 / 完成 / 取消 | 详情操作；计划中且具操作权 | 完成时要求实际信息和纪要；取消要求确认 | 已取消不可完成；记录状态、实际时间与纪要修改。 |
| 下一步 | 完成表单 | 可创建关联对象下的后续活动 | 放弃创建不阻断完成。 |

## 12. 页面状态

日历和列表切换保留当前时间范围；无计划时提示创建拜访。实际时间早于计划时间时要求二次确认并记录确认原因。
