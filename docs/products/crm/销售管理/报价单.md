# 报价单

## 1. 产品定位

### 1.1 解决什么问题

将商机中的产品、数量、价格、折扣和税率形成可版本化的商业报价。

### 1.2 使用角色

销售创建和发送报价；主管在授权范围内查看；管理员维护状态枚举。

### 1.3 与其他模块的关系

报价单关联商机和客户，引用产品明细；已接受报价可带入合同。

## 2. 核心业务流程

从商机创建草稿 → 选择产品与价格 → 计算总额 → 发送客户 → 接受、拒绝或作废 → 接受报价带入合同。

## 3. 页面设计

### 3.1 列表页

| 区块 | 设计 |
| --- | --- |
| 搜索 | 关键字、状态、客户、商机、负责人、有效期范围。 |
| 列 | 报价编号、版本、客户、商机、含税总额、有效期、状态、负责人、操作。 |
| 操作 | 查看、编辑草稿、发送、复制为新版本、接受、拒绝、作废。 |

### 3.2 详情页

| 区块 | 内容 |
| --- | --- |
| 顶部 | 报价编号、版本、状态、金额和关键动作。 |
| 基本资料 | 客户、商机、联系人、负责人、有效期、备注。 |
| 产品明细 | 产品、单位、数量、单价、折扣、税率、行金额和汇总。 |
| 关联 | 版本历史、活动、已接受后创建的合同。 |

### 3.3 新建 / 编辑

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 客户、商机 | 选择 | 是 | 商机必须属于客户。 |
| 产品明细 | 可编辑表格 | 是 | 至少一行；引用启用产品。 |
| 数量、单价、折扣、税率 | 数值 | 是 | 不得为负；行金额自动计算。 |
| 有效期、备注 | 日期、多行文本 | 否 | 到期后不可发送。 |

## 4. 数据模型

### 4.1 核心字段

编号、版本、客户、商机、联系人、负责人、状态、有效期、产品明细、税前金额、税额、含税总额和备注。

### 4.2 状态

草稿、已发送、已接受、已拒绝、已作废。

### 4.3 关联关系

一个商机可有多个报价版本；已接受报价可关联一个或多个合同。

## 5. 功能需求

### 5.1 查询

按状态、客户、商机、负责人和有效期查询。

### 5.2 新增

从商机或直接创建，自动带入客户与可选产品。

### 5.3 编辑

仅草稿可编辑；已发送报价通过复制生成新版本。

### 5.4 状态流转

草稿发送后为已发送；客户确认后为已接受；拒绝和作废为终态；同一商机同一时刻仅一个有效报价。

### 5.5 删除 / 作废

草稿可删除；已发送报价只能作废，不删除历史版本。

## 6. 权限与数据可见性

### 6.1 查看权限

继承商机和客户数据范围。

### 6.2 操作权限

创建、编辑、发送、接受、拒绝、作废和导出分别授权。

### 6.3 数据范围

商机负责人及部门决定报价默认可见范围。

## 7. 业务规则

行金额等于数量乘单价乘折扣；总额由明细汇总；产品资料在报价中保存快照；页面只展示枚举名称。

## 8. 异常与边界场景

停用产品不可加入新报价；已接受报价不可作废；有效期已过不可发送；商机丢单后不可新建报价。

## 9. MVP 范围

### 9.1 P0

产品明细、金额计算、版本、发送、接受、拒绝、作废和合同带入。

### 9.2 P1

审批、电子签、复杂定价和多币种。

### 9.3 暂不支持

自动邮件发送和在线支付。

## 10. 验收标准

销售可从商机创建报价并看到自动汇总金额；已发送报价通过新版本修改；已接受报价可带入合同。

## 11. 字段契约与交互细则

| 动作 / 字段 | 触发与前置条件 | 系统反馈与结果 | 异常恢复 / 审计 |
| --- | --- | --- | --- |
| 客户、商机 | 新建首选项 | 商机选择后自动回显客户与可选联系人 | 不属于客户的商机不可提交，提示重新选择。 |
| 产品明细与金额 | 草稿编辑 | 行金额、税额和总额实时计算；至少保留一行 | 数量、单价、折扣或税率非法时定位到单元格；停用产品不可新增。 |
| 发送 / 接受 / 拒绝 / 作废 | 详情状态操作 | 显示状态影响和确认；接受后可创建合同 | 已发送仅可复制新版本；终态按钮隐藏并保留时间线。 |

## 12. 页面状态

草稿无产品时显示添加产品引导；计算或保存失败保留编辑中的行。有效期过期时发送按钮置灰并说明原因；同商机已有有效报价时提示用户确认版本关系。
