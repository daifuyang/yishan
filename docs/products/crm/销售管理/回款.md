# 回款

## 1. 产品定位

### 1.1 解决什么问题

以合同为边界管理应收计划、实际到账和核销，让团队看到待回、已回和逾期金额。

### 1.2 使用角色

销售维护本人合同的回款信息；主管查看团队应收；管理员维护全部记录与回款方式枚举。

### 1.3 与其他模块的关系

回款计划和实际回款均归属合同，并间接关联客户、商机和报价。

## 2. 核心业务流程

合同生效 → 创建回款计划 → 到期前提醒 → 登记实际到账 → 核销计划 → 自动计算待回、部分回款、已回款或逾期。

## 3. 页面设计

### 3.1 列表页

| 区块 | 设计 |
| --- | --- |
| 视图 | 回款计划视图与实际回款视图。 |
| 搜索 | 客户、合同、状态、负责人、计划日期、到账日期、回款方式。 |
| 计划列 | 客户、合同、期次、计划日期、计划金额、已核销、待核销、状态、负责人、操作。 |
| 实际列 | 到账日期、客户、合同、到账金额、方式、核销状态、登记人、操作。 |

### 3.2 详情页

| 区块 | 内容 |
| --- | --- |
| 合同摘要 | 合同金额、计划总额、已回金额、待回金额和逾期金额。 |
| 计划明细 | 期次、计划日期、金额、已核销、状态和操作。 |
| 实际回款 | 到账日期、金额、方式、备注及核销去向。 |
| 时间线 | 计划调整、到账登记和核销记录。 |

### 3.3 新建 / 编辑

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 合同、期次 | 选择、数值 | 是 | 合同必须履约中。 |
| 计划日期、计划金额 | 日期、金额 | 是 | 计划合计不超过合同金额。 |
| 到账日期、到账金额 | 日期、金额 | 实际回款必填 | 金额不得为负。 |
| 回款方式 | 枚举下拉 | 实际回款必填 | 设置维护。 |
| 核销计划项、备注 | 多选、多行文本 | 否 | 可核销一个或多个计划项。 |

## 4. 数据模型

### 4.1 核心字段

计划：合同、期次、计划日期、计划金额、已核销金额、状态。实际：到账日期、到账金额、方式、备注、核销关系和登记人。

### 4.2 状态

回款计划为待回款、部分回款、已回款、已逾期；状态由到期日、计划金额和核销金额计算。

### 4.3 关联关系

一个合同有多个计划和实际回款；一笔实际回款可核销一个或多个计划项。

## 5. 功能需求

### 5.1 查询

支持客户、合同、状态、负责人、日期和方式查询。

### 5.2 新增

合同履约中后创建计划；到账后登记实际回款并选择核销项。

### 5.3 编辑

未核销计划可调整；已核销金额不可低于已核销部分；到账记录修改需保留审计。

### 5.4 状态流转

状态由计算得出，不允许人工修改；到期未全额核销自动为已逾期。

### 5.5 删除 / 作废

未核销计划可删除；已核销计划和实际回款不可物理删除，只能冲销或作废并留痕。

## 6. 权限与数据可见性

### 6.1 查看权限

继承合同和客户数据范围。

### 6.2 操作权限

计划维护、到账登记、核销、冲销和导出分别授权。

### 6.3 数据范围

合同负责人和部门决定默认可见范围。

## 7. 业务规则

计划金额合计不得超过合同金额；已核销金额不得超过计划金额；实际回款金额与核销状态分开记录。

## 8. 异常与边界场景

作废合同不可新增计划；重复到账提示但不阻断；跨合同核销不允许；冲销后重新计算计划状态。

## 9. MVP 范围

### 9.1 P0

计划、到账、核销、状态计算、逾期提醒和合同应收摘要。

### 9.2 P1

发票、退款、账龄分析和财务系统同步。

### 9.3 暂不支持

自动对账和多币种核算。

## 10. 验收标准

用户可建立不超过合同金额的计划、登记到账并核销；待回和逾期状态随日期与金额正确计算。

## 11. 字段契约与交互细则

| 动作 / 字段 | 触发与前置条件 | 系统反馈与结果 | 异常恢复 / 审计 |
| --- | --- | --- | --- |
| 回款计划 | 合同履约中且具计划维护权 | 录入期次、日期和金额，实时显示合同剩余额度 | 合计超合同金额时阻断并提示可用余额。 |
| 实际到账 / 核销 | 具到账登记权 | 选择一个或多个同合同计划项，实时显示可核销金额 | 跨合同或超额核销阻断；重复到账提示但可继续。 |
| 调整 / 冲销 | 具对应权限 | 确认影响后重算计划状态和合同摘要 | 已核销部分不可下调；记录前后金额、原因和操作者。 |

## 12. 页面状态

计划与实际到账切换保留筛选；无计划时引导建立计划。逾期、部分回款和已回款使用状态标签，均由系统计算且不可直接编辑。
