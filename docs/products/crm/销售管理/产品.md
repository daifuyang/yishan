# 产品

## 1. 产品定位

### 1.1 解决什么问题

维护可销售的标准产品目录，向报价和商机提供统一名称、单位、价格和税率。

### 1.2 使用角色

管理员维护目录；销售在商机和报价中选择已启用产品。

### 1.3 与其他模块的关系

产品可被商机和报价明细引用；不管理库存、成本或采购。

## 2. 核心业务流程

创建产品 → 设置分类、单位、标准价和税率 → 启用供销售选择 → 停用后保留历史明细。

## 3. 页面设计

### 3.1 列表页

| 区块 | 设计 |
| --- | --- |
| 搜索 | 关键字、分类、启用状态。 |
| 列 | 产品名称、编码、分类、单位、标准价、税率、状态、更新时间、操作。 |
| 操作 | 查看、编辑、启用、停用。 |

### 3.2 详情页

| 区块 | 内容 |
| --- | --- |
| 基本资料 | 名称、编码、分类、单位、说明。 |
| 商业信息 | 标准价、税率、启用状态。 |
| 使用记录 | 被商机和报价引用的历史摘要。 |

### 3.3 新建 / 编辑

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| 名称、编码 | 文本 | 名称是 | 编码唯一，名称提示重复。 |
| 分类、单位 | 枚举下拉 | 是 | 设置维护。 |
| 标准价、税率 | 金额、百分比 | 是 | 不得为负。 |
| 状态、说明 | 开关、多行文本 | 否 | 停用不可用于新报价。 |

## 4. 数据模型

### 4.1 核心字段

名称、编码、分类、单位、标准价、税率、状态和说明。

### 4.2 状态

启用、停用。

### 4.3 关联关系

产品可出现在多个商机和报价明细中。

## 5. 功能需求

### 5.1 查询

按关键字、分类和状态查询。

### 5.2 新增

管理员新建产品并维护价格、税率和枚举。

### 5.3 编辑

可修改未受历史保护的资料；历史报价保留当时快照。

### 5.4 状态流转

启用产品可用于新报价；停用只阻止新选择。

### 5.5 删除 / 作废

未被引用可软删除；已引用只能停用。

## 6. 权限与数据可见性

### 6.1 查看权限

销售可查看启用目录；管理员可查看全部。

### 6.2 操作权限

产品维护仅管理员或已授权角色可操作。

### 6.3 数据范围

产品目录为组织级共享数据。

## 7. 业务规则

产品不管理库存或成本；报价保存产品名称、单位、单价和税率快照，不随目录修改而覆盖。

## 8. 异常与边界场景

重复编码不可保存；停用产品不可加入新报价；价格和税率不得为负。

## 9. MVP 范围

### 9.1 P0

目录、分类、单位、标准价、税率和启停用。

### 9.2 P1

价格表、阶梯价、套餐和成本。

### 9.3 暂不支持

库存、采购和成本核算。

## 10. 验收标准

管理员可维护产品目录；销售仅能选择启用产品；历史报价明细不受后续目录修改影响。

## 11. 字段契约与交互细则

| 动作 / 字段 | 触发与前置条件 | 系统反馈与结果 | 异常恢复 / 审计 |
| --- | --- | --- | --- |
| 名称、编码 | 新建或编辑 | 编码唯一校验，名称重复展示候选 | 冲突时定位字段并保留输入。 |
| 价格、税率、单位 | 编辑表单 | 非负数校验并回显当前生效值 | 非法值说明取值范围。 |
| 停用 / 恢复 | 详情操作 | 二次确认后切换可用性 | 历史报价保留快照；记录状态变更。 |

## 12. 页面状态

无产品时有创建权用户看到新增引导；被报价引用的产品删除入口隐藏并提示改用停用。列表刷新失败保留当前数据和筛选。
