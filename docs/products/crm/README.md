# CRM 产品文档

## 1. 产品定位

面向尚未使用 CRM 的小型通用 B2B 销售团队，帮助团队持续回答：客户是谁、谁负责、下一步做什么、离回款还有多远。

## 2. 目标用户

系统管理员维护人员、角色和枚举；销售主管管理部门线索、客户与漏斗；销售人员处理本人负责的销售对象；售后人员在 P1 处理已授权客户的工单。

## 3. 核心业务闭环

来源枚举 → 线索 → 客户与联系人 → 商机 → 报价单 → 合同 → 回款。线索合格后创建或关联客户、联系人；商机按实际交易需要创建。电话、会议、邮件、拜访、任务和备注以活动形式关联业务对象。

## 4. 模块划分

### 4.1 市场管理

线索承接潜在客户并完成资格判断；线索池展示无负责人的线索，提供领取和分配。

### 4.2 客户管理

客户沉淀合作主体，联系人沉淀客户侧人员；客户公海展示无负责人的客户。

### 4.3 销售管理

商机管理销售预测，产品与报价支持商业方案，合同与回款记录签约和现金事实；拜访是活动类型，工单为 P1 售后闭环。

## 5. 核心对象关系

| 对象 | 唯一职责 | 关键关系 |
| --- | --- | --- |
| 线索 | 判断潜在客户是否值得投入销售资源 | 合格后关联客户、联系人和可选商机 |
| 客户 | 记录合作主体及归属 | 可关联多个联系人、商机、合同和工单 |
| 商机 | 记录可预期交易、阶段、金额和下一步 | 可关联多个报价，最终关联合同 |
| 合同 | 记录最终签约与履约事实 | 可拆分多个回款计划和回款记录 |
| 活动 | 记录销售行动 | 关联线索、客户、联系人、商机、报价或合同 |

负责人和公海归属独立于状态；来源、行业、阶段、原因、单位和回款方式等枚举由设置维护，业务页面仅展示名称。关键归属、状态、金额和日期变更必须可追溯。

## 6. MVP 范围

P0 覆盖线索到回款的可执行闭环、活动时间线、轻量数据权限和工作台提醒。评分、自动分配、审批、电子签、财务同步、复杂协同和完整工单流程不进入 P0。

## 7. 后续演进

后续按实际使用数据逐步增加自动化规则、预测模型、审批、电子签、财务集成、客户画像、字段级权限与工单 SLA；不以一次性复杂配置替代小团队的日常执行。
