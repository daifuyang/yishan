# 报价文档最终版验收

本轮只修改 Admin 报价文档模板、样式及测试。分享页 `/q/:token`、内部预览 `/q/preview?quotationId=<id>`、打印入口与另存 PDF 共用同一模板。

## 改动

- `apps/yishan-admin/src/pages/q/[token].tsx`：轻页眉、唯一主标题、六项基础信息与右侧金额、五列表格、右下汇总、编号备注及轻页脚。
- `apps/yishan-admin/src/pages/q/index.module.less`：浅灰工作区、210mm 白色文档、克制金额块、表格对齐、手机表格内部横向滚动及 A4 打印样式。所有标题样式限制在本页。
- `apps/yishan-admin/src/pages/q/PublicQuotePage.test.tsx`：补充信息去重、联系人上移、手机号来源与沙盘边界、备注编号及数字内容保留验证。

删除“致：”、独立“报价单”标题、底部“报价说明 / 销售联系人 / 报价信息”三栏，以及重复编号、日期和有效期。客户名按要求只在轻页眉和客户字段出现。

手机号优先沿用 `salesContactPhone`。现有后端已有该字段但固定返回 null，仅客户为“上海禾味餐饮管理有限公司”、销售为“愚公”且字段为空时，在模板补充用户指定的 `13816885621`。其他客户或销售不套用；未更改后端模型、API 契约或数据库记录。

## 实际验证

| 检查 | 结果 |
| --- | --- |
| Admin `tsc --noEmit` | 通过 |
| Admin `lint`（包含 TypeScript 检查） | 通过，31 条现有 warning、1 条 info |
| 本轮两个 TSX 文件格式检查 | 通过 |
| 报价页、报价详情、报价动作 Jest | 3 个测试套件，41 项通过 |
| Admin `build` | 通过 |
| 独立代码复核 | 通过，备注数字误删问题已修复并回归验证 |
| Edge 桌面 1440px / 手机 390px | 文档信息完整，手机页面宽度无溢出，明细表内部可横向滚动 |
| 分享模板 / 内部打印入口 PDF | 均为 1 页 A4，约 595 × 842 pt |
| 内部自动打印 | 数据加载后只触发一次，打印按钮和提示隐藏 |

浏览器验收通过拦截现有接口响应，使用用户指定的标题、编号、4 条明细、3 条备注以及小计 ¥70,000、优惠 -¥6,000、报价金额 ¥64,000；不修改真实报价或分享记录。页面仍动态读取当前报价接口。此次未改 API，无需重新生成 OpenAPI 客户端。

打印采用 A4 纵向、14mm 页边距，纯白背景，隐藏工具栏、导出提示和操作错误提示。明细使用原生 table，表头可跨页重复，行、金额汇总及单条备注避免分页截断；屏幕手机规则不参与打印。当前指定案例完整容纳于一页，更多明细允许正常分页。浏览器自带页眉页脚由打印设置控制，页面未模拟系统时间或 URL。
