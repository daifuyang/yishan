# CRM v1.2 UX 全量升级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实施 CRM v1.2 spec 的 7 个 US：仓库规范违例清零 + 批量操作 + 高级筛选 + 跟进富文本 + 工作台行动化 + 跟进聚合页 + 设置页拖拽排序/跟进模板/客户评分 ABCD。

**Architecture:** 后端先行（schema + endpoint + service + repository + 单测），前端跟进（组件 + 页面改造 + 单测），E2E 收尾（API + Admin 端到端冒烟）。每个 task 是一个完整的 TDD 循环：写测试 → 运行失败 → 实现 → 运行通过 → 提交。

**Tech Stack:** Fastify 5 + Drizzle ORM + TypeBox (后端)；React 19 + UmiJS 4 + Ant Design Pro 6 + TipTap 3 + dayjs (前端)；vitest (后端单测)；Jest (前端单测)；pnpm monorepo。

**Spec:** `specs/004-crm-v1.2-ux-overhaul/spec.md`（本 plan 与 spec 一起阅读，spec 已落地 commit `daf26f3`）

**Branch:** `004-crm-v1.2-ux-overhaul`

## Global Constraints

来自 spec 与仓库规范，**所有 task 必须遵守**：

- **后端**：
  - Node ≥ 22.22.1；pnpm 8.15.9
  - 所有表名以 `crm_` 前缀（meta.id = 'crm'）
  - 业务错误码段 **33xxx**（CRM_CUSTOMER_* / CRM_CUSTOMER_DUPLICATE / CRM_CUSTOMER_ALREADY_OWNED 等，见 `apps/yishan-api/src/modules/crm/schemas/error-codes.ts`）
  - SQL 只在 `repositories/` 写；`services/` 编排；`routes/` 只校验和塑形
  - TypeBox schema 优先定义（contract-first），再写 service / route
  - 枚举用 `Type.Union([Literal('xxx'),...])` closed union，禁止裸字符串
  - 事务用 `dbManager.transaction(async (tx) => ...)` 包裹，repository 接 tx 而非 drizzleDb
  - **不**引入新 EAV / DSL / 自定义字段平台
- **前端**：
  - 严禁 `window.prompt / window.alert / document.getElementById`
  - 操作列 `valueType: 'option'`, `<Space size={16}>` 包 `<a>`，禁止 `<Button type="link">`
  - 时间格式 `dayjs(value).format('YYYY-MM-DD HH:mm:ss')`，禁用 `toLocaleString()`
  - `PageContainer` **不传** `header.breadcrumb: {}`；`header.subTitle` 慎用，纯文本或省略
  - `ProTable` 列 `valueEnum` 用真实数据，不用 hand-written `<Tag>` render
  - 省市区用 `<ProFormRegionCascader>`（Yishan Core 已有，复用 `sys_region`）
  - 富文本用 `apps/yishan-components/yishan-tiptap`（已构建产物在 `dist/`）
  - Menu 路径 `/<id>/...`，**不**用 `/modules/` 前缀
- **提交**：Conventional Commits `feat: / fix: / refactor: / test: / docs: / chore:`
- **质量门**：每个 task 完成必须 `pnpm --filter yishan-api test` 全绿（≥350 测试）+ `pnpm --filter yishan-admin tsc --noEmit` 0 error

async batchTag(opts: {
  customerIds: number[]
  tagIds: number[]
  mode: 'add' | 'remove' | 'replace'
  operatorUserId: number
}) {
  let success = 0
  const failed: { id: number; code: number; message: string }[] = []
  for (const customerId of opts.customerIds) {
    try {
      await this.dbManager.transaction(async (tx) => {
        if (opts.mode === 'replace') {
          await tx.delete(crmCustomerTag).where(eq(crmCustomerTag.customerId, customerId))
        }
        if (opts.mode === 'add' || opts.mode === 'replace') {
          for (const tagId of opts.tagIds) {
            await tx.insert(crmCustomerTag).values({ customerId, tagId }).onDuplicateKeyUpdate({ set: { tagId } })
          }
        }
        if (opts.mode === 'remove') {
          for (const tagId of opts.tagIds) {
            await tx.delete(crmCustomerTag).where(and(
              eq(crmCustomerTag.customerId, customerId),
              eq(crmCustomerTag.tagId, tagId),
            ))
          }
        }
      })
      success++
    } catch (err: any) {
      failed.push({ id: customerId, code: err?.code ?? 50000, message: err?.message ?? 'unknown' })
    }
  }
  return { success, failed }
}

// apps/yishan-api/src/modules/crm/repositories/follow-up-template.repository.ts
import { and, eq, like, isNull, desc, sql } from 'drizzle-orm'
import { drizzleDb, type AppQueryDb } from '@/db'
import { crmFollowUpTemplate } from '../db/schema.js'

export class FollowUpTemplateRepository {
  constructor(private readonly db: AppQueryDb = drizzleDb) {}

  async list(query: { keyword?: string; enabled?: number; page?: number; pageSize?: number }) {
    const conds = [isNull(crmFollowUpTemplate.deletedAt)]
    if (query.keyword) conds.push(like(crmFollowUpTemplate.name, `%${query.keyword}%`))
    if (query.enabled !== undefined) conds.push(eq(crmFollowUpTemplate.enabled, query.enabled))
    const where = and(...conds)
    const offset = ((query.page ?? 1) - 1) * (query.pageSize ?? 20)
    const data = await this.db.select().from(crmFollowUpTemplate).where(where)
      .orderBy(crmFollowUpTemplate.sort, desc(crmFollowUpTemplate.id))
      .limit(query.pageSize ?? 20).offset(offset)
    const totalRows = await this.db.select({ c: sql<number>`count(*)` }).from(crmFollowUpTemplate).where(where)
    return { data, total: totalRows[0]?.c ?? 0 }
  }

  async findById(id: number) {
    const rows = await this.db.select().from(crmFollowUpTemplate).where(and(eq(crmFollowUpTemplate.id, id), isNull(crmFollowUpTemplate.deletedAt))).limit(1)
    return rows[0] ?? null
  }

  async create(input: typeof crmFollowUpTemplate.$inferInsert) {
    const result = await this.db.insert(crmFollowUpTemplate).values(input)
    return this.findById(Number((result as any).insertId))
  }

  async update(id: number, input: Partial<typeof crmFollowUpTemplate.$inferInsert>) {
    // isSystem=1 不允许改 name
    const current = await this.findById(id)
    if (!current) throw new BusinessError('CRM_TEMPLATE_NOT_FOUND', '模板不存在')
    if (current.isSystem === 1 && input.name && input.name !== current.name) {
      throw new BusinessError('CRM_TEMPLATE_SYSTEM_READONLY', '系统模板不可改名')
    }
    await this.db.update(crmFollowUpTemplate).set(input).where(eq(crmFollowUpTemplate.id, id))
    return this.findById(id)
  }

  async softDelete(id: number) {
    const current = await this.findById(id)
    if (!current) throw new BusinessError('CRM_TEMPLATE_NOT_FOUND', '模板不存在')
    if (current.isSystem === 1) throw new BusinessError('CRM_TEMPLATE_SYSTEM_READONLY', '系统模板不可删')
    await this.db.update(crmFollowUpTemplate).set({ deletedAt: new Date() }).where(eq(crmFollowUpTemplate.id, id))
  }
}

        followUpCount,
        statusName,
      })

    }
  })

import { drizzleDb, type AppQueryDb } from '@/db'
import { crmNotification } from '../db/schema.js'

export class NotificationRepository {
  constructor(private readonly db: AppQueryDb = drizzleDb) {}

  async countUnread(userId: number) {
    const rows = await this.db.select({ c: sql<number>`count(*)` }).from(crmNotification)
      .where(and(eq(crmNotification.userId, userId), eq(crmNotification.isRead, 0)))
    return rows[0]?.c ?? 0
  }

  async list(opts: { userId: number; unreadOnly?: boolean; page?: number; pageSize?: number }) {
    const conds = [eq(crmNotification.userId, opts.userId)]
    if (opts.unreadOnly) conds.push(eq(crmNotification.isRead, 0))
    const where = and(...conds)
    const offset = ((opts.page ?? 1) - 1) * (opts.pageSize ?? 20)
    const data = await this.db.select().from(crmNotification).where(where)
      .orderBy(desc(crmNotification.createdAt))
      .limit(opts.pageSize ?? 20).offset(offset)
    const totalRows = await this.db.select({ c: sql<number>`count(*)` }).from(crmNotification).where(where)
    return { data, total: totalRows[0]?.c ?? 0 }
  }

  async markAsRead(userId: number, notificationId: number) {
    const result = await this.db.update(crmNotification)
      .set({ isRead: 1, readAt: new Date() })
      .where(and(eq(crmNotification.id, notificationId), eq(crmNotification.userId, userId)))
    return (result as any).affectedRows > 0
  }
}

async setPrimaryInTx(contactId: number, tx: AppTx) {
  // 1) 先查出 contact 所属 customer_id
  const rows = await tx.select({ customerId: crmContact.customerId })
    .from(crmContact).where(eq(crmContact.id, contactId)).limit(1)
  if (rows.length === 0) throw new BusinessError('CRM_CONTACT_NOT_FOUND', '联系人不存在')

  // 2) 同 customer 其他 contact is_primary=0
  await tx.update(crmContact).set({ isPrimary: 0 })
    .where(and(eq(crmContact.customerId, customerId), ne(crmContact.id, contactId)))

  // 3) 当前 contact is_primary=1
  await tx.update(crmContact).set({ isPrimary: 1 }).where(eq(crmContact.id, contactId))
  return { customerId }
}

async importFromExcel(buf: Buffer, opts: { operatorUserId: number }) {
  const ExcelJS = require('exceljs')
  const wb = new ExcelJS.Workbook()
  await wb.xlsx.load(buf)
  const ws = wb.worksheets[0]
  if (!ws) return { imported: 0, failed: [] }
  
  const rows = ws.getSheetValues() // 第一行是表头
  const dataRows = rows.slice(1).filter((r: any) => r && r[1])
  if (dataRows.length > 1000) throw new BusinessError('CRM_CUSTOMER_IMPORT_TOO_LARGE', '单次最多 1000 行')
  
  let imported = 0
  const failed: { row: number; message: string }[] = []
  for (let i = 0; i < dataRows.length; i++) {
    const r = dataRows[i] as any
    try {
      await this.create({
        name: r[1],
        type: r[2] ?? 'enterprise',

      })

    } catch (err: any) {
      failed.push({ row: i + 2, message: err?.message ?? 'unknown' })
    }
  }
  return { imported, failed }
}

// apps/yishan-admin/src/modules/crm/components/DuplicateChecker/index.tsx
import { Alert } from 'antd'
import React, { useEffect, useState } from 'react'
import { checkDuplicate } from '@/services/crm'

export interface DuplicateCheckerProps {
  keyword?: string
  type?: 'enterprise' | 'individual'
  onJump?: (id: number) => void
}

export const DuplicateChecker: React.FC<DuplicateCheckerProps> = ({ keyword, type, onJump }) => {
  const [hits, setHits] = useState<Array<{ id: number; name: string; ownerUserName: string | null }>>([])

  useEffect(() => {
    if (!keyword || keyword.length < 1) { setHits([]); return }
    const timer = setTimeout(async () => {
      try {
        const res = await checkDuplicate(keyword, type)
        setHits(res.data ?? [])
      } catch { setHits([]) }
    }, 500)
    return () => clearTimeout(timer)
  }, [keyword, type])

  if (hits.length === 0) return null
  return (
    <Alert
      type="warning"
      showIcon
      message={
        <span>
          ⚠️ 发现 {hits.length} 个疑似重复：
          {hits.map((h) => (
            <a key={h.id} style={{ marginLeft: 8 }} onClick={() => onJump?.(h.id)}>
              {h.name}（{h.ownerUserName ?? '无人负责'}）
            </a>
          ))}
        </span>
      }
    />
  )
}

// apps/yishan-admin/src/modules/crm/components/ReminderBadge/index.tsx
import { Badge, Popover, List, Typography } from 'antd'
import { BellOutlined } from '@ant-design/icons'
import { history } from '@umijs/max'
import React, { useEffect, useState } from 'react'
import { getUnreadCount, listNotifications, markAsRead } from '@/services/crm'

export const ReminderBadge: React.FC = () => {
  const [count, setCount] = useState(0)
  const [items, setItems] = useState<any[]>([])

  useEffect(() => {
    const tick = async () => {
      try {
        const res = await getUnreadCount()
        setCount(res.data.count)
        if (res.data.count > 0) {
          const list = await listNotifications({ unreadOnly: true, pageSize: 10 })
          setItems(list.data ?? [])
        } else { setItems([]) }
      } catch { /* ignore */ }
    }
    tick()
    const timer = setInterval(tick, 60_000)
    return () => clearInterval(timer)
  }, [])

  const handleClick = async (item: any) => {
    await markAsRead(item.id)
    setCount(c => Math.max(0, c - 1))
    if (item.link) history.push(item.link)
  }

  const content = (
    <List
      size="small"
      dataSource={items}
      renderItem={(item: any) => (
        <List.Item onClick={() => handleClick(item)} style={{ cursor: 'pointer' }}>
          <Typography.Text>{item.title}</Typography.Text>
        </List.Item>
      )}
    />
  )

  return (
    <Popover content={content} trigger="click" placement="bottomRight">
      <Badge count={count} offset={[-4, 4]}>
        <BellOutlined style={{ fontSize: 20, cursor: 'pointer' }} />
      </Badge>
    </Popover>
  )
}

// apps/yishan-admin/src/modules/crm/pages/customers/index.tsx (key parts)
import { PageContainer, ProTable, ProFormSelect, ProFormText, DrawerForm } from '@ant-design/pro-components'
import { useEffect, useRef, useState } from 'react'
import { history } from '@umijs/max'
import { BulkActionBar } from '../../components/BulkActionBar'
import { AdvancedFilterDrawer } from '../../components/AdvancedFilterDrawer'
import { DuplicateChecker } from '../../components/DuplicateChecker'
import { listCustomers, listStatuses, listSources, searchUsers, batchTransfer } from '@/services/crm'

const Customers: React.FC = () => {
  const actionRef = useRef<any>(null)
  const [selectedRowKeys, setSelectedRowKeys] = useState<React.Key[]>([])
  const [statuses, setStatuses] = useState<any[]>([])
  const [sources, setSources] = useState<any[]>([])
  const [users, setUsers] = useState<any[]>([])
  const [filterOpen, setFilterOpen] = useState(false)
  const [createOpen, setCreateOpen] = useState(false)
  const [dupKeyword, setDupKeyword] = useState('')

  useEffect(() => {
    Promise.all([listStatuses(), listSources(), searchUsers('', 50)]).then(([s, src, u]) => {
      setStatuses(s.data.map((x: any) => ({ value: x.id, label: x.name })))
      setSources(src.data.map((x: any) => ({ value: x.id, label: x.name })))
      setUsers((u.data ?? []).map((x: any) => ({ value: x.id, label: x.realName ?? x.username })))
    }).catch(() => {})
  }, [])

  return (
    <PageContainer header={{ title: '客户管理' }}>
      <BulkActionBar selectedRowKeys={selectedRowKeys} onBatchTransfer={() => {}} onBatchExport={() => {}} />
      <ProTable
        headerTitle="我的客户"
        actionRef={actionRef}
        rowKey="id"
        rowSelection={{ selectedRowKeys, onChange: setSelectedRowKeys }}
        search={{ labelWidth: 'auto' }}
        pagination={{ pageSize: 10, showSizeChanger: true }}
        columns={[
          { title: '客户名称', dataIndex: 'name', valueType: 'text' },
          { title: '客户状态', dataIndex: 'statusId', valueType: 'select', valueEnum: Object.fromEntries(statuses.map(s => [s.value, { text: s.label }])) },
          { title: '客户来源', dataIndex: 'sourceId', valueType: 'select', valueEnum: Object.fromEntries(sources.map(s => [s.value, { text: s.label }])) },
          { title: '负责人', dataIndex: 'ownerUserId', valueType: 'select', valueEnum: Object.fromEntries(users.map(u => [u.value, { text: u.label }])) },
          { title: '更新时间', dataIndex: 'updatedAt', valueType: 'dateTime' },
        ]}
        request={async (params) => {
          const res = await listCustomers({ page: params.current ?? 1, pageSize: params.pageSize ?? 10 })
          return { data: res.data, success: true, total: res.total }
        }}
        toolBarRender={() => [
          <a key="filter" onClick={() => setFilterOpen(true)}>高级筛选</a>,
          <a key="create" onClick={() => setCreateOpen(true)}>新建客户</a>,
        ]}
      />
      <AdvancedFilterDrawer open={filterOpen} onClose={() => setFilterOpen(false)} onApply={() => { actionRef.current?.reload(); setFilterOpen(false) }} statuses={statuses} sources={sources} tags={[]} users={users} />
      <DrawerForm title="新建客户" open={createOpen} onOpenChange={setCreateOpen} onFinish={async () => { actionRef.current?.reload(); return true }} drawerProps={{ destroyOnClose: true, width: 720 }}>
        <ProFormText name="name" label="客户名称" rules={[{ required: true }]} fieldProps={{ onChange: (e) => setDupKeyword((e.target as HTMLInputElement).value) }} />
        <DuplicateChecker keyword={dupKeyword} type="enterprise" onJump={(id) => history.push(`/crm/customer-detail?id=${id}`)} />
        <ProFormSelect name="statusId" label="客户状态" options={statuses} />
        <ProFormSelect name="sourceId" label="客户来源" options={sources} />
      </DrawerForm>
    </PageContainer>
  )
}

// apps/yishan-admin/src/modules/crm/pages/pool/index.tsx (key parts)
import { PageContainer, ProTable } from '@ant-design/pro-components'
import { message } from 'antd'
import { useRef, useState } from 'react'
import { history } from '@umijs/max'
import { BulkActionBar } from '../../components/BulkActionBar'
import { listPool, claimCustomer, batchClaim, maskPhone } from '@/services/crm'

const Pool: React.FC = () => {
  const actionRef = useRef<any>(null)
  const [selectedRowKeys, setSelectedRowKeys] = useState<React.Key[]>([])

  const handleSingleClaim = async (id: number) => {
    await claimCustomer(id)
    message.success('已认领')
    actionRef.current?.reload()
    // 不跳详情
  }

  const handleBatchClaim = async () => {
    const res = await batchClaim({ customerIds: selectedRowKeys as number[] })
    message.success(`已认领 ${res.data.success} 个客户，${res.data.failed.length} 个已被其他销售认领`)
    setSelectedRowKeys([])
    actionRef.current?.reload()
  }

  return (
    <PageContainer header={{ title: '客户公海', subTitle: '尚未被任何销售认领的客户；敏感联系方式已脱敏。' }}>
      <BulkActionBar selectedRowKeys={selectedRowKeys} onBatchTransfer={handleBatchClaim} />
      <ProTable
        headerTitle="公海客户"
        actionRef={actionRef}
        rowKey="id"
        rowSelection={{ selectedRowKeys, onChange: setSelectedRowKeys }}
        search={{ labelWidth: 'auto' }}
        pagination={{ pageSize: 10, showSizeChanger: true }}
        columns={[
          { title: '客户名称', dataIndex: 'name', render: (_, r) => <a onClick={() => history.push(`/crm/customer-detail?id=${r.id}`)}>{r.name}</a> },
          { title: '类型', dataIndex: 'type', valueEnum: { enterprise: { text: '企业' }, individual: { text: '个人' } } },
          { title: '电话', dataIndex: 'phone', render: (_, r) => <span style={{ color: '#999' }}>{maskPhone(r.phone)}</span> },
          { title: '更新时间', dataIndex: 'updatedAt', valueType: 'dateTime' },
          {
            title: '操作', dataIndex: 'option', valueType: 'option', fixed: 'right', width: 160,
            render: (_, record) => <a onClick={() => handleSingleClaim(record.id)}>认领</a>,
          },
        ]}
        request={async (params) => {
          const res = await listPool({ page: params.current ?? 1, pageSize: params.pageSize ?? 10 })
          return { data: res.data, success: true, total: res.total }
        }}
      />
    </PageContainer>
  )
}

export default Pool
