本次在当前 `dev` 分支工作区开发，未提交、部署或修改已有业务数据库。数据库验收使用本机 MySQL 的随机 `yishan_demo_test_<20位十六进制>` 临时数据库，验收后清理。

## 实现与版本

- Ant Design X / XMarkdown 2.9.0，Ant Design 6.4.3。
- AI SDK 7.0.142，`@ai-sdk/react` 4.0.146，OpenAI Provider 4.0.95。
- 验证命令使用仓库固定的 Node 22.22.1 与 pnpm 8.15.9。
- 唯一聊天状态引擎为 `useChat`；官方 X 组件负责展示。
- 页面最终路径为 `/demo/ai-chat`。System 菜单种子强制业务模块使用自身前缀，不能由 Demo 贡献 `/ai/chat`；未为此添加 Core 例外。
- API 维持 CommonJS，AI SDK 位于原生 `.mts` → `.mjs` 边界。编译后的服务保留动态 `import()`。
- 安装依赖后保留原锁文件已有依赖解析，只加入 AI/X 所需闭包；`pnpm install --frozen-lockfile --ignore-scripts` 成功。

## 实际数据库与浏览器

实际编译 API 验证了迁移、重复执行种子、登录、未登录 401、角色权限、会话创建/列表/重命名/删除和其他用户会话的读取、修改、删除、生成全部不可访问。单元测试另外覆盖跨实例租约、失效租约恢复、取消、错误清理、请求大小限制和敏感上游错误脱敏。

使用生产 Admin 构建和真实 Fastify/MySQL 进行了浏览器验收：菜单与直接 URL 访问、欢迎页、浮窗入口、新建对话、历史加载、重命名、确认删除及删除后列表同步、缺少模型配置的明确提示、失败重试、复制、Shift+Enter 换行、草稿在两种形态及关闭重开之间保持一致。

额外使用**仅存在于临时 QA 脚本中的 OpenAI 协议替身**验证了完整流式链路：

- 浮窗生成中展开页面只产生一个上游请求。
- 关闭浮窗后重新打开不取消请求；停止按钮取消上游并保存部分回复及 `aborted` 终态。
- 重新生成不增加用户消息数量。
- XMarkdown 的标题、表格、代码块、链接与复制可用；模型文本中的 script 标签按文本显示且未执行。
- 页面与浮窗在 1920×1080、1440×900、1280×800、768×1024、390×844 五种尺寸均位于视口内，输入区域可见。

该协议替身不属于正式实现，也不代表真实模型联调成功。生产代码没有假响应、演示模型地址或前端密钥。

另通过项目开发环境现有 SettingDrawer 切换 realDark，检查欢迎区、侧栏、输入框和 Markdown。发现并修正 CodeHighlighter 默认浅色代码背景，使用其 `highlightProps` 接入当前 Ant Design Token；实际暗色代码前景与背景已复查。
