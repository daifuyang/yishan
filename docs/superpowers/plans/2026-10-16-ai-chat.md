# AI chat implementation plan

**Goal:** Deliver authenticated, persisted AI chat in the existing Demo Admin page and floating panel.

**Architecture:** Demo owns the business routes, schema, repository and service. A native ESM `.mts` runtime imports AI SDK 7; CommonJS services load its compiled `.mjs` through native dynamic import. A stable Admin provider owns one useChat instance and drafts; both views consume it.

**Spec:** User's complete AI assistant task and technology adjustment in this session are authoritative. Direct implementation has been explicitly requested; work stays on current `dev` branch.

**Constraints:** AI SDK 7, Ant Design X 2, Ant Design 6; no X SDK state hooks, Tailwind, shadcn or mock production responses. Existing menu/RBAC and source-first boundaries remain authoritative. No production schema application or deployment.
